# Security Policy

Report vulnerabilities to security@REPLACE_ME (or a GitHub private
vulnerability report on this repo). Acknowledgment within 48 hours.
Please do not open public issues for exploitable findings.

Scope notes: the scorer processes untrusted public metadata by design;
findings that let crafted metadata inflate a score, break the daily
snapshot series, or exfiltrate CI credentials are highest severity.
Score disputes are not security reports — see DISPUTES.md.
